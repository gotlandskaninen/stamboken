# Typsnitt för intygen

`pedigree.html`). Alla under SIL Open Font License 1.1, licenstexten i `OFL.txt`.

- IBM Plex Sans och IBM Plex Mono, från IBM/plex 1.1.0. Copyright © 2017 IBM Corp., with Reserved Font Name "Plex".
- Source Serif 4, från adobe-fonts/source-serif 4.005R. Copyright 2014–2023 Adobe (http://www.adobe.com/), with
  Reserved Font Name "Source".

Samma filer som pappersblanketterna i stamboken-drift (`blanketter/gemensam/fonts`).
